# MySQL Lite 功能文档

更新时间：2026-11-02 17:41

本文档描述当前代码已实现的全部用户可见能力，作为验收与回归依据。技术栈：Electron 38 + Vue 3 + TypeScript + electron-vite + naive-ui + Monaco + mysql2。

---

## 1. 产品定位

Windows 桌面 MySQL / TiDB 轻量客户端，覆盖：连接管理、对象树浏览、SQL 查询与结果编辑、表结构编辑。不追求替代 Navicat 全功能（外键/触发器设计、同步、用户管理等未做）。

数据目录：Electron `userData`，由 `package.json` 的 `name` 决定。当前源码名为 `mysql-lite-release` 时，目录为 `%APPDATA%\mysql-lite-release`（连接与工作区均在此）。

## 2. 主界面布局

### 2.1 左侧图标栏（rail）

| 按钮 | 行为 |
|---|---|
| 连接 | 切换到连接树侧栏，并展开侧栏 |
| 历史 | 切换到 SQL 历史侧栏，并展开侧栏 |
| 设置 | 切换到设置侧栏，并展开侧栏 |
| 折叠 / 展开 | 仅折叠或展开侧栏，不改变当前 rail |

说明：连接按钮**不再**通过再次点击折叠；折叠只走「折叠」按钮。

### 2.2 侧栏

- 宽约 280px；折叠后主工作区占满剩余空间。
- **连接**：连接树（见第 3 章）。
- **历史**：本次会话执行过的 SQL，最多 30 条，去重后新的在前；点击一条则新建查询标签并填入该 SQL（不自动执行）。**不落盘**，关应用即清空。
- **设置**：只读模式开关（默认开）。开启后查询执行仅允许 SELECT / SHOW / EXPLAIN / DESC / DESCRIBE / USE。删除表、表结构保存等显式写操作自行传 `readonly: false`，不受此开关拦截，但仍走危险语句确认。

### 2.3 主工作区

- **查询**（`module=query`）：SQL 多标签工作台。
- **表结构**（`module=structure`）：单表结构编辑页；由连接树右键「编辑表结构」进入。

### 2.4 底栏状态

显示：连接状态（绿点/灰点）、当前连接文案、光标行列、字符集、服务器版本等（以界面为准）。

### 2.5 全局保护

- Ctrl+R / Ctrl+Shift+R 禁用，避免误刷新整窗。

## 3. 连接管理

### 3.1 连接配置

入口：连接树顶「+ 新建连接」，或连接节点右键「编辑连接」。

字段（常规）：名称、主机、端口、用户名、密码、默认库、字符集、超时秒数。

高级：

- **显示的库**：勾选后连接树只展示勾中的库；全选或从未设置则显示全部。
- SSL 页为占位，未实现真实 SSL 配置。

能力：

- **测试连接**：不落盘，返回版本信息或错误。
- **保存**：密码经系统 `safeStorage` 加密写入 `connections.json`；列表接口剥离明文密码。
- **删除连接**：二次确认；若为当前打开连接则先断开。

### 3.2 打开 / 断开

- 展开连接节点即打开连接池；成功提示「连接成功」，失败中文错误。
- 已打开连接节点前缀为绿点。
- 右键连接：「编辑连接」「断开连接」「删除连接」。

### 3.3 连接树结构

层级：连接 → 库 → 表。

- 库懒加载：首次展开库时 `SHOW` / information_schema 拉表清单。
- 单击库：设为当前库（`currentDb`）。
- 双击表：新建查询标签并自动执行 `SELECT * FROM \`db\`.\`table\` LIMIT 200`。

### 3.4 连接树键盘筛选（无搜索框）

1. 先点击连接树获得焦点。
2. 直接敲字母：按**包含匹配**（大小写不敏感）隐藏不匹配节点；祖先为挂住命中子节点而保留。
3. 匹配字黄底高亮（无下划线）。
4. Backspace 删一字；Esc 清空并恢复展开状态。
5. 未展开的库下面的表尚未加载，筛不到。

### 3.5 右键菜单

**表**：

| 项 | 行为 |
|---|---|
| 查询表数据 | 同双击表 |
| 编辑表结构 | 切到表结构页，加载该表 |
| 复制表名 | 剪贴板为纯表名（无反引号） |
| 导出数据 | `SELECT * … LIMIT 1000` 后存 CSV |
| 删除表 | 二次确认后 `DROP TABLE`，再刷新该库表清单 |
| 刷新 | 重新拉取该库表清单 |

**库**：

| 项 | 行为 |
|---|---|
| 刷新 | 重新拉取该库表清单；新建表应可见 |

**连接**：见 3.2。

## 4. SQL 查询工作台

### 4.1 标签与工作区持久化

- 多 SQL 标签；内容防抖写入 `workspace.json`。
- 下次启动恢复标签与活动标签；单标签正文超过 1MB 时提示是否加载，拒绝则本次不打开该标签，文件中原文保留。
- 结果区高度默认 540px（160–4000），拖分隔条后写入工作区。

### 4.2 工具栏

- **实例 / 库**下拉：执行目标；换实例会断开并打开新实例。
- **执行**（Ctrl+Enter）：有选中执行选中；否则执行光标所在语句。
- **停止**：取消正在执行的查询 / 计数。
- **格式化 / 压缩 / 清空 / 历史**（历史写入侧栏列表）。
- EXPLAIN 入口（若界面提供）：对当前语句做执行计划。

编辑器右键「执行(ctrl+enter)」与 Ctrl+Enter 规则相同。

### 4.3 编辑器

- Monaco，MySQL 语法高亮、行号。
- 快捷键：撤销/重做、剪切复制粘贴、全选、查找替换、行注释、移动行、复制行、Ctrl+Enter 执行。
- 补全：关键字（排序保证 WHERE 优先于 WHEN 等）；当前库表/视图/列；FROM/JOIN 后先表名再「已展示的库」；语句中写了其他库名则补该库对象。

### 4.4 安全与执行

- 只读模式：见 2.2。
- 危险语句（DROP / TRUNCATE / ALTER / GRANT / REVOKE / RENAME，以及无 WHERE 的 DELETE/UPDATE 等，以解析为准）需二次确认后带 `confirmed` 重试。
- 默认单次最多约 1000 行预览；超时可配置（界面/选项默认 60s 量级）。
- 无 LIMIT 的 SELECT 自动补 `LIMIT 1001 OFFSET n` 做批次预览；底栏上一批/下一批；满批时后台 COUNT，底栏「统计中…」后显示总行数。语句自带 LIMIT 不改写、不额外 COUNT。
- 查询耗时只统计语句执行本身（不含注释查询等附属请求）。

### 4.5 结果区标签

- **查询结果**：网格（第 5 章）。
- **执行信息**：语句、影响行数、错误等。
- **执行计划**：EXPLAIN 结果。
- 空状态图标垂直对齐。

普通执行时结果区可显示「执行中…」；结果网格保存后的重查使用透明遮罩，数据仍可见。

## 5. 结果网格

### 5.1 展示

- 表头字段名；悬停表头整格显示列注释（懒加载 `SHOW FULL COLUMNS`，按连接+库+表缓存，容量有上限）。
- NULL 置灰显示为 `NULL`。
- 列宽按本批内容估算，上限 300px；表头右缘可拖。
- 分页：页大小切换、跳页；底栏可有批次导航。

### 5.2 选择与剪贴板

- 单击单元格：选中（蓝框）。
- 双击或 Enter：可写列进入编辑。
- 点最左列空白（非复选框）：整行选中（浅蓝背景，非整行每格蓝框）。
- Ctrl+C：选中格复制单元格；整行选中复制 TSV 行。NULL 复制为文本 `NULL`。
- Ctrl+V：从焦点格向右向下填入（tab/换行拆分）；文本 `NULL` 还原为数据库 null；空字符串仍为空字符串。不自动增行。
- 「+」新增草稿行并整行选中，便于立刻粘贴。

### 5.3 编辑与保存

前提：结果可判定为**单表**、结果含该表**全部主键列**、列可映射回基表。联表 / 缺主键 / 表达式列 → 只读。

- 「+」增行、「−」删勾选行（先划掉）、「×」撤销、「✓」保存。
- 保存：参数化 INSERT / UPDATE / DELETE；含删除时提示「将删除 n 行」。
- 成功后重查当前批次；重查期间透明遮罩 +「执行中…」。
- 顶栏只读开关**不拦截**网格保存。

### 5.4 导出

- 导出 CSV：UTF-8 BOM、标准转义；默认文件名「表名-本地时区时间.csv」（非法文件名字符替换）；对话框可改名。

## 6. 表结构编辑

### 6.1 入口与布局

- 仅连接树右键「编辑表结构」打开；**无左侧全库表清单**。
- 顶栏：返回查询（主色按钮）、连接状态、库名标签、表名、视图只读标记；右侧保存 / 查询数据 / 复制表名 / 导出结构。
- 第二行：左侧表说明，右侧记录数 / 表大小 / 字符集 / 引擎。
- Tab：字段、索引、DDL 预览。

### 6.2 字段

- 表格展示：平时纯文本；点击单元格任意位置进入编辑。
- 列：序号、字段名（内容估宽上限 300）、类型、长度、小数位、非空、默认值、主键、注释（剩余宽度）。
- 所有列可拖宽；表头不换行。
- 工具栏：添加、插入、删除、上移、下移。
- 主键只在字段页勾选；不在索引页维护 PRIMARY。

### 6.3 索引

- 二级索引：名称、字段（多选）、唯一；可添加/删除。
- PRIMARY 不在此列表。

### 6.4 保存

- 对比草稿与加载基线，生成一条 `ALTER TABLE`。
- 确认框展示 SQL；点执行后全屏透明遮罩防重复提交。
- 写回时尽量保留未在界面编辑的 AUTO_INCREMENT / unsigned / ON UPDATE 等（依赖 EXTRA 与原 COLUMN_TYPE）。
- 视图 DDL 只读，无保存。
- 有未保存修改时返回查询或切换目标表会询问。

### 6.5 其它

- 查询数据：跳转查询并 `LIMIT 200`。
- 复制表名：纯表名。
- 导出结构：当前 `SHOW CREATE TABLE` 存为 `.sql`。

## 7. 安全边界

- `contextIsolation` 开、`nodeIntegration` 关；Renderer 仅调 preload 白名单。
- SQL 与标识符参数化 / 反引号转义；CSV 流式写出。
- 密码不明文落盘、接口剥离凭据。

## 9. 已知限制 / 与早期方案偏差

1. SSL 配置页占位，未接通。
2. 结果集矩形多选复制未做。
3. SQL 历史仅会话内存，非持久化。
4. 表结构不支持外键、触发器、表选项、表注释编辑。
5. 连接树筛选不搜索未展开库内的表。
6. TiDB 上部分 ALTER（如改聚簇主键）可能被服务器拒绝，界面展示报错即可。
7. `publish-clean` 会改写源码 `package.json` 的 `name`，从而改变 userData 目录名。
8. 早期文档中「表结构左右分栏表清单」已废弃，以第 6 章为准。
